## 🌟 About

**Twine Game** is a complete, playable **interactive fiction** experience built with **Twine 2** and the **Harlowe** story format. It's a mystery-adventure where your choices shape the story — and lead to one of **12 unique endings**.

The game is fully open source, making it a perfect **learning template** for anyone who wants to see how a real Twine project is structured, styled, and shipped.

> 💡 **Perfect for:** Interactive fiction fans, Twine learners, game design students, and writers exploring branching narratives.

## 🧩 Project Structure

```
📖 twine-game/
├── 🎯 story/
│   ├── passages/              # Individual Twine passages
│   │   ├── chapter-1.twee
│   │   ├── chapter-2.twee
│   │   └── endings.twee
│   ├── variables.twee         # Story variables
│   └── macros.twee            # Custom macros
├── 🎨 styles/
│   ├── theme.css              # Custom Harlowe styling
│   └── fonts/
├── 💾 saves/                  # Save system integration
├── 🧪 tests/                  # Passage link validation
└── 📖 docs/                   # Story bible & credits
```
